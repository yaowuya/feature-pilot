# Vue 前端代码质量规范

配合 [公共规范](common.md) 使用，未标注【建议】的条款为【必须】。根据 settings 的 appRoot、实际 Vue/构建版本及客户覆盖启用；组件库、store、HTTP client、i18n 和 token 读取客户项目，不预设私有库、目录或品牌。

## F01 — 组件、命名与复用

- Vue 2.7 / Vue 3 且工具链支持时，新普通业务组件优先 `<script setup>`；客户有明确组件 API 规范时遵循该规范。Vue 2.6 沿用受支持的 Options API 或已经配置的 Composition API，不为规范升级框架。
- 不顺手迁移无关存量组件；keep-alive/递归 name、宏和混合 script 只使用当前版本/插件确实支持的方式，不因 lint 中有 Vue 3 规则就使用 Vue 3 专属能力。
- 复用项目已有组件和已配置库，不为相同基础能力重复封装或新增依赖；业务组合组件有真实复用点才抽取。组件 API、注册、slot/event 从当前代码核对。
- 文件/组件名、import 标识及模板标签遵循项目既有约定；无明确约定时采用统一可读的 Vue 命名方式，API 原始字段不为风格改名。
- 动态可编辑/排序/删除列表使用稳定业务 key，不用 index；纯静态无状态展示可按实际条件使用 index。避免同节点 v-if/v-for 的版本优先级差异。
- props 声明类型，可变默认值使用 factory；通过 emit 或项目支持的模型协议更新父级，不原地修改 props/嵌套引用。暴露 API 保持最小并匹配调用方。

## F02 — 响应式、状态与生命周期

- 局部状态使用当前版本支持的能力，共享领域状态沿用已存在的 Vuex/Pinia 等方案；不把所有 Vue 项目强制为某个 store，不为临时状态创建全局状态或 EventBus。
- Vuex 按 mutation/action 约定写状态；Pinia 按实际 action/patch 与项目约定处理，不机械套用 Vuex 限制。缓存/持久化按账号、业务/租户和资源隔离，上下文切换清理过期数据。
- Vue 2.6 / Vue 2.7 核对对象属性增删和数组下标的响应式限制，按需要使用预声明、`Vue.set`/`Vue.delete`/`splice` 或整体替换；Vue 3 使用实际 Proxy/ref 语义，不混用两代假设。
- 解构 props/reactive/store 时核对是否保留响应性，使用当前版本支持的方式；watch 明确依赖与 deep/immediate 的必要性。computed 保持纯计算，不请求、写其他状态或启动定时器。
- 事件、轮询、计时器、Observer、编辑器/图表实例在实际版本对应的销毁/unmount 生命周期释放；keep-alive 同时处理停用/激活，不重复注册或让过期回调改写状态。

## F03 — API 调用与异步正确性

- 使用客户已验证的 API 模块/HTTP client 和真实签名，不在组件/store 绕过鉴权、CSRF、权限及错误处理，不预设目录或导出方式。上传、Blob、原始响应和下载资源释放单独核对。
- 初始化/依赖变化在生命周期/watch 发起，用户操作在事件处理发起；异步事件处理允许，不在插值、computed 或渲染绑定触发异步副作用。
- loading 在请求前设置、`finally` 释放；写操作禁用按钮且拦截重复进入，前端防重不代替后端幂等。并行请求用独立状态/计数，不提前解除其他请求的 loading。
- 搜索、分页、切换资源使用取消、序号或归属检查保证最后一次用户意图生效；返回前复验当前资源/弹窗状态，避免旧响应覆盖新数据。
- 异常有真实失败/重试状态，统一请求层已反馈时避免重复提示；关闭全局反馈时调用方承担处理，不静默吞掉。取消请求不当业务失败弹窗。
- 配置未加载不等于空配置，在真实数据就绪前不以默认表单覆盖服务端值。核对 HTTP/业务 result/code/data、分页及空值的实际解包层级，不把 HTTP 200 当全成功。

## F04 — 样式、Token 与构建

- 使用现有样式组织；已配置 Tailwind 时简单布局可复用工具类，复杂样式按项目 CSS/SCSS 等模式处理，不为规范安装样式库或重复定义已有工具能力。
- 品牌色、字号等复用真实设计 token/CSS 变量，不猜变量名、不硬编码品牌值；业务状态映射语义 token。图表需要具体值时从主题解析，用户真实颜色数据按输入校验而非误判为品牌 token。
- 组件样式按当前方案局部作用域，全局规则/库补丁进入已有全局入口；浮层挂载、teleport 和深层选择器核对当前 Vue/库版本并限定范围。
- 固定视觉样式放样式表/工具类；运行时宽高、位置或图形数据允许 style 绑定，不用它固化品牌 token。
- Tailwind 等静态扫描工具使用可识别的完整类映射或已核实 safelist，不拼接不可扫描的类名。
- 资源路径、动态 import、外置依赖核对当前生产构建，不硬编码开发 URL；遵守实际 lint/stylelint 配置，关闭检查不自动取消对应安全/行为规范。

## F05 — 性能与资源

- 长列表采用实际分页/虚拟滚动方案，限制依据产品需求和可验证性能；没有客户阈值时评估实际渲染规模，不将示例数字强制为所有数组或展示的上限。
- 路由页面与大编辑器/图表/预览按当前构建支持的方式懒加载，不在首屏同步引入无关重依赖。
- 重计算合理缓存，模板保持简单；大循环查找预建 map，避免每次渲染重复排序/过滤整表、大对象复制或重复请求。
- 轮询、重试和请求批次有界，失败/退出后停止；Object URL、事件、图表/编辑器和文件预览资源及时释放。

## F06 — 表单、权限、安全与可访问性

- 表单按实际校验 API 等待校验结果并定位错误；必填、范围、长度、类型和组合约束与后端一致，不替代后端校验。确认成功后才清空/关闭，失败保留输入。
- 删除、执行、发布等高影响操作遵循当前交互确认目标和影响，有 loading/禁用及成功/失败反馈；批量部分失败如实展示。
- 复用项目真实权限控件/action，业务禁用与权限拒绝区分；隐藏按钮/路由不是后端授权证明。
- 加载、空、错误、无权限、成功和未保存状态明确，提供重试/返回；控件有 label、图标有可访问名称、键盘可操作、焦点返回合理。
- 提示不只靠颜色；语义 token 核对对比度，文案沿用项目翻译入口，不因 script setup 绕过国际化。
- v-html、Markdown、SVG/富文本中的不可信内容经白名单或可靠净化；后端返回不默认安全。链接/下载校验协议和来源，外链按需隔离 opener。
- 不在日志、持久化 store、localStorage、错误提示或构建产物硬编码/暴露凭据；敏感凭据的存储遵循项目经确认的认证设计，不为调试关闭 CSRF/权限/校验。

## F07 — 验证与报告

- 从实际配置选取相关静态检查、构建和测试，区分修复/只读模式，改写后复查 diff；脚本未覆盖的修改文件不能算通过，不为规范安装工具。
- 在允许且隔离的环境验证正常/加载/空/错误/无权限、重复提交、竞态和关键表单；样式核对主题、实际支持视口、滚动与浮层，不为桌面产品强加未要求的移动适配。
- 检查控制台和网络，无错误不代表业务成功；截图用于视觉证据，网络/交互用于接口和行为证据。启动前检查真实服务代理，不触发未授权业务写操作。
- 无工具/环境时记录未验证项、原因与影响；规范结论与功能缺陷分开，不把未验证包装成已确认故障。注释和适度设计遵循 [工程质量契约](../engineering-quality.md)。
